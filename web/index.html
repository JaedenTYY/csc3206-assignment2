How the Algorithms Expand States

Uniform-Cost Search

priority = g(n)

Explores based strictly on accumulated cost. Guaranteed optimal, but expands many states blindly in all directions.

Greedy Best-First

priority = h(n)

Explores based strictly on estimated remaining cost. Extremely fast, but ignores distance already traveled. Not guaranteed optimal.

A* Search

priority = g(n) + h(n)

Balances both costs. Expands fewer states than UCS while still guaranteeing the mathematically optimal route.

Problem Formulation

State Representation

State is a tuple (Location, VisitedSet). There are 193 consistent reachable states in the metric tour, forming a subset of the 448 theoretically possible (7 × 2⁶) pairs.

Initial & Goal States

Start: ("SU", {})
Goal: (L, {M1..M6}) where returning to SU is not required.

Assumptions & Limitations

  • Static snapshot environment (no live traffic).
  • Deterministic graph costs.
  • Single vehicle routing.
  • Carbon emission acts as a linear proxy distance.

Future Improvements

  • Multi-objective composite optimization.
  • Time-window constraints for members.
  • Geospatial Mapbox/Leaflet overlays.
