Search Logic Comparison

Uniform-Cost Search

priority = g(n)

Explores based strictly on accumulated cost. Guaranteed optimal, but expands many states blindly in all directions.

Blind Optimality

Greedy Best-First

priority = h(n)

Explores based strictly on estimated remaining cost. Extremely fast, but ignores distance already traveled. Not guaranteed optimal.

Fast Suboptimality

A* Search

priority = g(n) + h(n)

Balances both costs. Expands fewer states than UCS while still guaranteeing the mathematically optimal route.

Informed Optimality

A* Heuristic Admissibility

Because the driving graph is directed and asymmetric, direct edge costs are not a valid lower bound. The A* heuristic must establish a metric closure to guarantee admissibility.

  • 1 Calculate directed shortest-path distances d*(a,b) using Dijkstra for all remaining unvisited nodes.
  • 2 Symmetrize the edges to create an undirected lower-bound metric: w(a,b) = min(d*(a,b), d*(b,a)).
  • 3 Construct a Minimum Spanning Tree (MST) using Prim's algorithm over this closure.
h(n) =
min(outgoing_cost(current, remaining))
+
MST_cost(remaining_metric_closure)
